## 项目经历

### 项目一：基于 Spring Cloud 的在线选课管理系统

**时间**：2025.09 - 2026.02 &nbsp;&nbsp; **角色**：独立开发者 &nbsp;&nbsp; **GitHub**：github.com/xxx/CourseSelectionSystem

**项目简介**：面向高校的分布式选课系统，覆盖学生/教师/管理员三类角色，涵盖课程发布、在线选课、成绩管理、教学评价等核心教学流程。

**技术栈**：Spring Boot 2.7、Spring Cloud 2021、MyBatis-Plus、Spring Data JPA、MySQL 8.0、Redis、Eureka、Gateway、Vue 静态前端

**核心职责与成果**：

1. **微服务架构设计**：基于 Maven 多模块搭建 9 个子模块（common-lib 公共库、eureka-server、gateway-server、web-service 等），将微服务思想落地到课程管理子系统；定义统一的 `Result<T>` 响应格式与 `BusinessException` 异常体系。

2. **选课核心流程**：实现"容量校验 → 重复检测 → 候补队列 → 自动提升"四步事务控制，配合 MySQL 行锁与 Redis 缓存选课人数，解决高并发下超卖与数据不一致问题。

3. **成绩计算引擎**：设计"平时 40% + 实验 20% + 期末 40%"的加权计算服务，封装为 Strategy 策略模式，新增评分维度只需添加一个实现类即可。

4. **安全与稳定性**：基于 BCrypt 加密用户密码，Session + 拦截器实现 RBAC 权限控制；对所有动态排序字段使用白名单 Map 防止 SQL 注入；全局异常处理统一返回 Result 包装。

5. **数据建模**：独立设计 9 张业务表（学院-系部-专业-学生-课程-选课-成绩-角色-权限），对高频查询（选课列表、成绩统计）建立复合索引，复杂查询响应时间从 800ms 降至 120ms。

**项目规模**：140+ Java 文件 / 16 个 Controller / 33 个前端页面 / 9 张数据表

### 项目二：基于 LLM 的个人智能助理（Agent）

**时间**：2026.03 - 2026.05 &nbsp;&nbsp; **角色**：独立开发者

**项目简介**：基于大语言模型的智能助理系统，支持自然语言对话、天气查询、待办管理等工具调用场景。

**技术栈**：Spring Boot、Spring AI、OpenAI API、SSE 流式输出、Redis

**核心职责与成果**：

1. **工具调用框架**：实现"用户输入 → 意图识别 → 工具调度 → 结果生成"的闭环 Agent 流程，将天气/待办/翻译等功能抽象为 `Tool` 接口，支持插件式扩展（新增工具 < 30 行代码）。

2. **流式对话体验**：基于 SSE（Server-Sent Events）实现打字机效果，前端通过 `ReadableStream` 实时渲染，首字延迟控制在 500ms 以内。

3. **会话管理**：设计多轮对话上下文管理方案，针对上下文丢失、超时等问题引入会话快照 + 摘要压缩机制，在 8K token 限制下支持最长 30 轮对话。

4. **链路可观测**：记录每次工具调用的 prompt、参数、耗时、token 消耗，沉淀日志中间件便于问题排查与成本分析。

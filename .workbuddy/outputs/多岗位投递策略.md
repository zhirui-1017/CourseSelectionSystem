## 二、各岗位简历怎么改

### 2.1 Java 后端版（主投，投 100 家）

**求职意向**：Java 后端开发实习生

**技能模块**：
```
后端框架：Spring Boot、Spring Cloud（Eureka/Gateway）、Spring Security
数据访问：MyBatis-Plus、Spring Data JPA、MySQL
工具：Git、Maven、Postman、Lombok
基础：Java 17、集合、多线程、JVM
```

**项目一描述（重点改这段）**：
> 基于 Spring Cloud 微服务架构的在线选课管理系统 | 独立开发
> - 9 个 Maven 模块：Eureka 注册中心 + Gateway 网关 + 5 个业务微服务 + 公共库 + 前端服务
> - 16 个 REST API 接口，9 张数据表，覆盖学院-系部-专业三级架构、三角色权限、选课全流程
> - 选课核心：MySQL 行锁防超选 + 候补队列自动提升 + @Transactional 事务一致性
> - 统一封装：Result<T> 响应封装 + GlobalExceptionHandler 全局异常 + BCrypt 密码加密
> - 安全防护：排序字段白名单防 SQL 注入 + Session 拦截器 RBAC 权限控制

### 2.2 测试开发版（副投，投 50 家）

**求职意向**：测试开发实习生 / 软件测试实习生

**技能模块**：
```
编程语言：Java、Python
测试工具：Postman、JUnit
测试方法：接口测试、边界测试、等价类划分
开发经验：Spring Boot 后端、MySQL、Git
```

**项目描述改写**：
> 基于 Spring Boot 的在线选课系统 | 独立开发 + 测试
> - 独立设计并实现 16 个 REST API 接口，完成接口联调和功能测试
> - 编写测试用例覆盖正常流程、异常输入（重复选课/超容量/权限越界）、边界条件
> - 使用 Postman 进行接口测试，验证 HTTP 状态码和返回数据结构
> - 设计统一响应封装 Result<T>，规范错误码和异常处理流程

**额外加一句**：
> 熟悉软件测试理论，了解自动化测试（pytest/Selenium），有后端开发经验能更好地理解被测系统

### 2.3 Python/AI 应用版（副投，投 30 家）

**求职意向**：Python 后端开发实习生 / AI 应用开发实习生

**技能模块**：
```
编程语言：Python、Java
AI/数据：OpenAI API、Pandas、Matplotlib
后端：Flask/Django（了解）、Spring Boot
工具：Git、Postman
```

**项目顺序调整**：AI Agent 项目放第一！

**项目一**：
> 个人 AI 智能助理（Agent 系统）| 独立开发
> - 基于 Spring Boot + OpenAI API 构建 AI 对话助手，支持自然语言交互、知识查询、工具调用
> - 设计 Agent 工作流：用户意图识别 → 工具选择 → 参数提取 → 结果生成 → 多轮对话
> - 前后端分离架构，前端实时流式展示对话内容
> - 处理长对话上下文丢失问题，优化会话管理和分片处理逻辑

**项目二**（选课系统，简化版）：
> 基于 Spring Boot 的选课系统后端 | 独立开发
> - 16 个 REST API、MySQL 数据库设计、BCrypt 密码加密

### 2.4 前端开发版（备选，投 20 家）

**求职意向**：前端开发实习生

**技能模块**：
```
前端：HTML5、CSS3、JavaScript（ES6+）、AJAX/Fetch
工具：Git、Chrome DevTools
后端了解：Spring Boot、MySQL（能配合后端联调）
```

**项目描述改写**：
> 在线选课系统前端开发 | 独立开发
> - 独立完成 33 个 HTML 页面开发，覆盖管理员/学生/教师三个角色端
> - 封装统一 API 请求模块（app-api.js）：fetch 封装、HTML 转义防 XSS、日期格式化、通知组件
> - 实现分页组件、搜索筛选、表单验证等通用功能
> - 与后端 16 个 REST API 接口联调，处理跨域和 Token 认证

### 2.5 运维/技术支持版（保底，投 20 家）

**求职意向**：IT 实习生 / 技术支持实习生

**技能模块**：
```
系统：Linux 基础命令、Windows 运维
网络：TCP/IP、HTTP 协议
开发：Java、Python、SQL
工具：Git、Maven
```

**项目描述简化**：
> 在线选课系统全栈开发 | 独立开发
> - 独立完成前后端开发和数据库设计
> - 熟悉 Linux 环境部署、MySQL 数据库管理
> - 有网络编程和系统排查经验

| 渠道 | 投递量 | 回复率 | 特点 |
|------|--------|--------|------|

## 七、绝对不要做的事

1. ❌ **不要等简历"完美"了再投** → 80 分就投，边投边改
2. ❌ **不要只投一个岗位** → Java + 测试 + Python 并行
3. ❌ **不要只投大厂** → 中小公司才是拿 offer 的主力
4. ❌ **不要在意薪资差 50 块** → 第一份实习看成长不是看钱
5. ❌ **不要拒绝面试练手** → 哪怕不想去也面，积累经验
6. ❌ **不要在周一/周五投** → 周二/三/四投递回复率最高
7. ❌ **不要只等线上** → 有内推机会一定用

# 6 周实习冲刺计划（7月13日 → 8月31日）

> **目标**：9 月前拿到至少 1 个实习 offer
> **策略**：广撒网 + 快准备 + 多岗位并行
> **时间预算**：每天 3-4 小时，周末可加到 6 小时

---

## 一、先认清现实

| 优势 | 劣势 |
|------|------|
| 有真实的微服务项目（9 模块、140+ 文件） | 专升本学历，部分大厂简历关会被卡 |
| 有 AI Agent 项目经验 | 无任何企业实习经历 |
| 懂 Spring Cloud 全套、MyBatis-Plus、JPA | 面试经验不足，可能紧张说不出话 |
| 懂前端（HTML/CSS/JS） | 算法刷题量不够，笔试可能挂 |
| 在校生身份（可走日常实习，不走秋招） | 时间紧（7 周内要出 offer） |

**核心策略**：
1. **不要只投 Java 后端** → 同时投 测试开发 / Python 后端 / 前端 / 运维 / 技术支持
2. **不要只投大厂** → 中小公司、外包、国企 IT 部门都投
3. **不要等准备好了再投** → 简历改好就立刻投，边面试边补
4. **日常实习 ≠ 秋招** → 门槛低很多，中小公司几乎有项目就能进

### 4.3 项目话术模板（背熟！）

**面试官问：「介绍一下你的项目」**

> 「我做了一个基于 Spring Cloud 微服务架构的在线选课系统。整个项目是 Maven 多模块结构，有 9 个模块：一个 Eureka 注册中心、一个 Gateway 网关、5 个按业务域拆分的微服务（用户、学生、教师、课程、选课），还有一个公共库模块和前端服务。
>
> 技术栈是 Spring Boot 2.7 + Spring Cloud 2021 + MyBatis-Plus + JPA + MySQL。我设计了 9 张表，覆盖学院-系部-专业三级组织架构、学生/教师/管理员三角色权限、课程管理和选课全流程。
>
> 选课是核心业务。我做了几个关键设计：第一，用 MySQL 行锁 + 容量校验防止超选；第二，课程满员后自动进入候补队列，有人退课时自动按时间顺序提升候补学生；第三，成绩按平时 40% + 实验 20% + 考试 40% 自动计算。我还做了统一响应封装 Result<T>、全局异常处理、BCrypt 密码加密、排序字段白名单防 SQL 注入。
>
> 前端部分我写了 33 个 HTML 页面，覆盖管理员、学生、教师三个端，用原生 JS + fetch 调后端 API。」

**面试官问：「项目中遇到什么难点？」**

> 「最大的难点是选课的并发问题。比如一门课容量 40 人，如果 50 人同时点选课，不能超过 40 人成功。
>
> 我一开始用先查后插的方式，发现有并发问题——两个线程同时查到当前 39 人，都插入就超了。后来改用 MySQL 的 SELECT ... FOR UPDATE 行锁，在事务里先锁住课程行，再查容量，再插入选课记录，保证原子性。
>
> 另一个难点是候补队列的自动提升。退课时我要把最早进入候补的学生提升为已选，这个操作必须在退课事务里完成，我用 @Transactional 保证退课+提升是一个原子操作。」

**面试官问：「微服务怎么拆的？为什么要拆？」**

> 「按业务域拆。学生、教师、课程、选课各自是独立服务，有自己的数据库表。好处是各模块独立开发部署，坏处是跨服务调用需要处理 Session 共享问题。
>
> 我现在用了 Eureka 做服务注册发现，Gateway 做统一入口和路由。但坦白说，目前因为 Session 跨服务共享的问题，Gateway 配置的是把请求统一转发到 web-service，微服务路由暂时注释掉了。如果要真正拆开，需要引入 Redis 共享 Session 或者改成 JWT 无状态认证，这是我后续计划优化的点。」

> 💡 **关键技巧**：主动说出项目的不足和改进方向，面试官会觉得你有思考能力，比假装完美强 100 倍。

## 九、紧急情况预案

### 情况 1：投了 100 家，0 回复
**原因**：简历有问题
**对策**：
1. 检查求职意向是否写清楚
2. 检查是否有明显错别字
3. 降低期望薪资 500
4. 找学长/老师帮忙看简历
5. 尝试换平台（BOSS → 实习僧 → 牛客）

### 情况 2：有面试但全挂
**原因**：面试表达不行
**对策**：
1. 每次面试录音，回来复盘
2. 对着镜子练自我介绍
3. 先投不想去的公司练手
4. 重点练项目讲解（最核心）

### 情况 3：8 月中还没 offer
**原因**：时间不够了
**对策**：
1. 扩大岗位范围（投运维、技术支持、实施工程师）
2. 接受更低薪资（80-100/天）
3. 接受更远通勤
4. 找远程实习
5. 找外包公司的实习岗（门槛最低）

### 情况 4：offer 不满意但快到 9 月
**对策**：**先接了**，进去干 1-2 个月，简历上有企业经历后再跳。第一份实习的最大价值不是公司多好，而是**简历上有企业名**。
